# Customer Segmentation

## Overview
A Python-based Customer Segmentation project that uses data analysis and machine learning to identify groups of customers.

## Technologies Used
- Python
- Pandas
- NumPy
- Scikit-learn
- Matplotlib
- Seaborn
- Streamlit

## Features
- Customer data analysis
- Customer segmentation
- Data visualization
- Interactive Streamlit dashboard

## Run Locally
1. Install Python.
2. Install dependencies using:
   python -m pip install -r requirements.txt
3. Run the application:
   python -m streamlit run streamlit_app.py
